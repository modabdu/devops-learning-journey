## Section 02 - The Linux Terminal in Depth

### Lecture 1: Terminals, Consoles, Shells, Commands
- Terminal: the program that displays the window
- Console: the text-based interface
- Shell: the command interpreter (e.g., bash)
- Command: the actual instruction

### Lecture 2: Linux Command Structure
- Format: command [options] [arguments]
- Options modify behavior (e.g., -l, --all)
- Arguments are inputs to the command
